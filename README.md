# Classic Tracker

App personal para registrar el entrenamiento de la rutina Classic Physique (5 días, bloques de 6 semanas) y medir el progreso. Funciona sin conexión y se instala en Android como app.

## Usar en el teléfono

1. Abre la dirección de GitHub Pages del repositorio en Chrome para Android.
2. Menú ⋮ → "Instalar app" (o "Agregar a pantalla principal").
3. La primera vez, indica el lunes en que empieza tu bloque.

## Cómo se registra una serie

- Cada serie viene precargada con lo que hiciste la última vez (o con la carga sugerida si toca subir).
- Tocar ✓ la registra y arranca el descanso. Ajusta con − y + si hiciste algo distinto; mantener presionado repite.
- Toca el número de kg para escribir la carga (la primera vez de cada ejercicio).
- RIR: un toque en 0, 1, 2, 3 o 4+.

## Respaldo

Pestaña Yo → Exportar respaldo, una vez por semana, y guárdalo en Drive. Los datos viven en el teléfono hasta que llegue la sincronización (Fase 4).
